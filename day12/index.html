LRU Cache Architecture

Design and implement an in-memory Least Recently Used (LRU) Cache with O(1) time complexity for both get and put operations.

description

Problem Specification

An LRU cache evicts the least recently accessed key when its capacity limit is reached. Your implementation must combine a Doubly Linked List and a Hash Map to achieve constant time lookups and updates.

Key Requirements
  • Initialize with fixed capacity capacity > 0.
  • get(key): Return key value if exists, else -1.
  • put(key, value): Insert or update. Evict LRU node if full.
  • Write comprehensive unit tests covering edge cases.
